# GML Translate PR #3 与 Core PR #1 审查结果

2026-11-19，审查起点为插件 b70484d 和 Core c1d1344。检查了两个 PR 相对已发布版本基线的运行代码、测试和依赖锁文件。发现的三项可复现问题均已修复并补充回归。

审查修正版为 **GML Translate 2.11.2-rc.6 / Core 0.9.18**。版本递增使浏览器资源与页面缓存使用新的命名空间。

1. **P1，旧扫描会把较新的完整 manifest 再次写成 stale。已修复。**

   当文章固定链接在渲染期间改变，更新后的发现先完成时，较旧发现返回后的失效分支仍会无条件 mark_stale。全局版本变更也有相同路径。数据库夹具中直接观察到较新的 complete 快照被改成 stale。

   失效分支现在使用渲染开始时的快照及全局版本进行条件写入，旧任务返回 gml_resource_changed 并保留较新快照。新增原文和全局变更两组交错回调测试。修复位于 Core 的 src/class-resource-manifest-discovery.php。

2. **P2，编码子目录会造成重复语言前缀及脚本异常。已修复。**

   站点路径含编码空格或 UTF-8 百分号编码时，原实现用编码目录长度截取已解码路径，可能读不到语言段并抛出脚本异常。PHP 同样混用了原始目录和解码路径。扩展夹具在原实现中得到 44 项 PHP 失败、162 项浏览器差异及两次脚本异常。

   现在先按一致的原始路径定位安装目录，再对相对路径进行解码分类，浏览器也从 URL 对象取得规范化目录。标准和自定义内容目录的比较采用同一表示。覆盖根目录、普通子目录、编码空格目录及编码 UTF-8 目录，47 类地址的锚点、表单、动态节点和属性更新均通过。修复位于插件 assets/js/language-switcher.js、Core src/class-output-buffer.php 与 src/class-url-helper.php。

3. **P2，原文更新后可能继续等待旧扫描失败的退避时间。已修复。**

   原实现按资源键复用旧重试记录。同一个资源更新或全局版次改变后，即使安排了较早唤醒，工作器仍可能跳过它，退避上限为一小时。实测保留十分钟旧记录后更新同一资源，扫描未恢复。

   文章和分类更新会清理过期重试状态，全局版本变化会提前唤醒工作器并使旧代次退避失效。旧格式重试记录会从 manifest 补全代次。渲染期间的源变更会重置旧尝试次数。原文未变化的持续失败继续保留退避。修复位于 Core src/class-resource-manifest-manager.php。
