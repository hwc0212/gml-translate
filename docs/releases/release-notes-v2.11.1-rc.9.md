# GML Translate v2.11.1-rc.9

本候选版修复源站内容修改后翻译任务发现不及时的问题，并与 GML AI SEO 对齐 AI Provider。

## 主要变化

- 保存已发布页面、文章、产品等公开内容后，只记录一次增量扫描；保存请求不调用 AI，也不自动恢复暂停队列。
- 支持 Google Gemini、DeepSeek、Qwen、OpenAI，凭据分别加密保存。
- 批次内相同文本只翻译一次，prompt 只包含当前文本命中的术语和保护词。
- `<40°C`、`<70%`、尺寸和其他纯技术值直接保留，不再消耗 API token。
- 旧译文、人工译文、Translation Memory、URL、语言设置和暂停状态全部保留。

## 升级后验证

1. 保持翻译暂停，修改并保存一个测试页面。
2. 等待 WordPress Cron 完成增量扫描，确认只出现该页面的新文本。
3. 测试已保存的 Provider 连接，再只启动一个语言的小批量。
4. 在未登录窗口核对正文、标题、canonical、hreflang 和语言切换链接。

不要清空翻译库或直接重试全部历史失败。需要回退时先暂停任务，再恢复旧插件文件；本版本没有数据库结构迁移。
